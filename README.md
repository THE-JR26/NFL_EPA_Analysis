# NFL_Analysis

## Overview

This project analyzes NFL quaterback performance using Expected Point Added(EPA).

The goal is to identify games where quarterbacks produce negative EPA, but their team still won the game.

The project uses an end-to-end analysis pipeline:
NFL Play-By-Play Data -> Python ETL -> MySQL Database -> SQL Analysis -> Power BI Dashboard

# Technologies
  **Python**
  **Pandas**
  **MySQL**
  **SQLAlchemy**
  **PowerBI**
  **nflreadpy**

## Business Question
How Often do NFL quarterbacks win despite producing negative EPA?

## Key Findings
  **Analyzed 2,341 quarterback game performances**
  **Identified 285 wins despite negative EPA**
  **Approximately 12.2% of quarterback performances won despite negative EPA**
